“The sales report is slow and sometimes wrong. Can you fix it?”a one-line request from the sales team, Monday morning

1 · Questions I ask

  • ❓Which report, and who opens it? The weekly report by region, used by 12 managers.
  • ❓How slow? About 40 seconds to open.
  • ❓Wrong how? Some returns are missing when you filter by week.

2 · What I check in the system

  • 🔎Reproduced it. A return booked on a Sunday lands in the next week.
  • 🔎The 40 seconds come from recalculating all history every time the report opens.

3 · The task I write

Problem
The weekly report counts Sunday returns in the wrong week, and it takes about 40 seconds to open.
Reproduce
Book a return on a Sunday, open the report for that week, and the return is missing.
Accept when

Given a return booked on a Sunday, when I open that week, then it is counted in that week.

Given the report is opened, then it loads in under 5 seconds.

Priority
P2: wrong numbers in a report people use for decisions.

✅ Ready for development. No questions left.
